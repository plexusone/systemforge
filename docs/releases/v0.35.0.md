# v0.35.0

**Release Date:** 2026-11-18

Asking a birth date before an account is created can feel intrusive. The
sign-up age question can now link to the deployment's own page explaining
why it asks, such as the laws it follows.

## Why we ask

- **`SignupAgePage.ReasonURL`.** When set, the age question and the refusal
  each show a link to it.
- **`SignupAgePage.ReasonLabel`.** The link's text, "Why we ask" by default.
- **Nothing changes without it.** A page with no `ReasonURL` shows no link.

See [Minimum sign-up age](../guides/signup-age.md).

The release adds no breaking change.

## Upgrading

Set the URL with the page's wording in the host binary:

```go
svc, err := systemauthsvc.New(ctx, cfg, systemauthsvc.Options{
    SignupAgePage: systemauth.SignupAgePage{
        ReasonURL: "https://www.example.com/age/",
    },
})
```

An embedded server takes it with `systemauth.WithSignupAgePage`.

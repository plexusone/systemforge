# v0.32.1

**Release Date:** 2026-11-06

The organization console shows the signed-in person the way the
applications do, and connections show what their last check found.

- **Name and picture in the console.** The console's session,
  `GET /console/bff/session`, now carries the person's name, email and
  avatar, so its profile menu shows their picture instead of a placeholder.
  `console.Options.Profile` supplies them; `systemauthsvc` fills it from
  SystemAuth's directory, the same source as the `name` and `picture`
  claims. Without it, or when it fails, the console works as before.
- **`systemauth.Server.Principal`** returns a human principal's profile
  from social login's directory.
- **What a connection reaches.** With connectforge v0.7.0, each
  connection's `health.details` in the connections API lists what its
  last successful check found, such as the Search Console properties an
  account can read. A failed check keeps the last ones.

The release adds no breaking change.

## Upgrading

Nothing is required. A deployment running the console through
`systemauthsvc` shows the person's name and picture after upgrading.
Existing connections have no details until their next check.

## Dependencies

- `github.com/plexusone/connectforge` 0.7.0.

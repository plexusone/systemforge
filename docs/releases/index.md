# Releases

Release notes, one file per version, newest first. The
[changelog](changelog.md) is generated from `CHANGELOG.json` and lists every
change with its commit.

The latest release, [v0.15.0](v0.15.0.md), completes the organization model:
organizations without a plan, application roles and entitlements,
collaborators and resource grants, real-time access invalidation and the
`authz` mode configuration. It is a breaking release with migrations 0004 to
0009; read its upgrade notes first.
